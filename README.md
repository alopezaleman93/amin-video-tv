# Amín cumple 8 — TV Video

Página web independiente para reproducir el video del cumpleaños en una televisión, en bucle y a pantalla completa.

## Cómo agregar el video

1. Exportá el video desde Canva como MP4.
2. En este repositorio, elegí **Add file → Upload files**.
3. Subí el archivo con este nombre exacto: `jurassic.mp4`.
4. Confirmá con **Commit changes**.

## Activar GitHub Pages

1. Abrí **Settings → Pages**.
2. En **Build and deployment**, elegí **Deploy from a branch**.
3. Seleccioná la rama `main` y la carpeta `/(root)`.
4. Tocá **Save** y esperá a que GitHub publique el sitio.

El enlace será: https://alopezaleman93.github.io/amin-video-tv/

## En la televisión

Abrí el enlace en el navegador de la TV y tocá **“Tocar para iniciar…”** una vez. Eso permite activar el audio y solicitar pantalla completa. El video se repite automáticamente.

**Nota:** el archivo del video todavía no está incluido. Hay que subir `jurassic.mp4` al repositorio.
